## English

AppGacha 0.1.3 makes switching between the Machine, Shelf, and Space smoother and fixes issues with sign-in status, capsule imports, and capsule isolation.

- **Smoother navigation with live 3D.** The Shelf and Space keep their animated 3D capsules and render only the previews in view. Returning to the Machine preserves your wish draft. Resizing the Space keeps the current capsule open.
- **Sign-in status updates immediately.** After signing in with an email verification code or a password, the desktop app refreshes the account display and checks cloud sync eligibility without a restart. The password setup step stays open for first-time email sign-ins.
- **More reliable imports.** Capsule names no longer affect where they can be installed. Concurrent imports use separate staging directories, and a failed import no longer leaves a partially installed capsule in the Shelf.
- **Stronger capsule isolation.** Each capsule can load its own resources, and the host checks the requesting page before granting access to a capsule capability.
- **More reliable Shelf and Space updates.** Fixed duplicate event subscriptions and kept the Space sidebar in sync with the open capsule if a tab change fails to save.

Available for **Windows x64** and **macOS Apple Silicon**.

## 中文

AppGacha 0.1.3 优化了扭蛋机、收藏柜和扭蛋空间的切换体验，并修复了登录状态、扭蛋导入和运行隔离相关的问题。

- **切页更顺滑，保留实时 3D。** 收藏柜与扭蛋空间仍有原来的 3D 胶囊动效，只渲染可见预览。切回扭蛋机时保留许愿草稿，调整扭蛋空间大小时继续使用当前扭蛋视图。
- **登录成功后立即刷新状态。** 用邮箱验证码或密码登录后，账号显示和云同步资格会自动刷新，无需重启。首次通过邮箱登录时，设置密码的步骤也会保留，方便继续操作。
- **导入更可靠。** 扭蛋名称无法改变安装目录。并发导入使用独立暂存目录，失败时收藏柜里不会留下装了一半的扭蛋。
- **加强扭蛋运行隔离。** 每颗扭蛋只能加载自己的资源，宿主会检查调用页面的来源，再决定是否允许使用扭蛋能力。
- **修复收藏柜和空间的状态更新。** 清理了重复的事件订阅，空间切换保存失败时，侧栏会恢复到实际打开的扭蛋。

支持 **Windows x64** 和 **macOS Apple Silicon**。
