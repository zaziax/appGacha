# 愿望工具台（构想）

用户创建一页或多页工作面板，自由画格、拖动和调整大小，在每个格子里写下希望它做什么。格子可以各自使用，也可以把一份数据供给多个格子使用。

每个模块声明自己的输入和输出，包括数据含义、结构和关键字段。例如训练记录和饮食记录都有日期，组合统计模块可以按日期比较训练日与休息日的饮食。

- 新建或修改格子时，AI 助手检查已有模块，提出或更新连接，必要时生成数据转换。含义、粒度或来源有歧义时再向用户确认。
- 已确定的连接由宿主执行。用户新增记录、筛选或换文件时，由数据总线更新相应模块。界面位置和数据连接分别保存。
- 拖动格子或修改样式时保留数据和连接。改变输入输出结构时，检查受影响的模块，兼容时保留连接，遇到歧义时提示用户处理。
- 用户可查看每个格子的数据来源、转换方式和连接状态。跨页访问健康、饮食或财务数据时，按用户表达的用途确定范围。

首个体验场景：先做训练和饮食记录，再随手画一格许愿「比较训练日和休息日的饮食」，用已有数据自动接通。之后再用财务页验证跨页连接。

此文记录产品方向，实现范围待定。
