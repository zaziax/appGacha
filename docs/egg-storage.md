# 自定义扭蛋存储目录

入口：**设置 → 通用 → 扭蛋存储目录**。

- 显示、打开当前目录，选择新目录，恢复默认目录，取消尚未生效的更改。
- 默认勾选复制已有扭蛋和数据，目标必须是空的专用文件夹。完整退出并重新启动后复制，原目录保留，不自动删除。复制结束后只使用新库，不同时读写两份库。
- 取消复制可切换到另一个已有扭蛋库；原目录里的应用不会删除，但也不会显示在新库中。
- 关闭到托盘不算退出。切换期间当前会话仍使用旧目录；后台构建、同步、MCP 与打开的应用不会中途改变路径。
- 目录中直接保存各个 `名称.gacha/` 文件夹及其 `data/`。生成、导入、分享导入、云端下载、MCP 入柜与启动加载都通过 `dataRoot('eggs')` 使用同一个位置。
- API 密钥、账号、设置、遥测、MCP 授权和构建草稿不随这个选项搬移；暂存区、失败记录与升级备份也维持原位置。这不是搬移整个用户数据目录。

## 配置与生效

`<userData>/egg-storage.json` 保存当前目录和待重启应用的 `{directory, copyExisting}`。没有配置时沿用原规则：开发版为 `<appPath>/eggs`，安装版为 `<userData>/eggs`。

启动时先应用目录变更，再发现扭蛋、启动提醒/MCP、处理桌面快捷方式和文件导入。期间到达的启动请求排队，不会向旧库导入。路径在运行期间保持不变。

## 复制保护

- 拒绝磁盘/卷根目录、程序/内部数据目录，以及当前目录的父目录、子目录；解析真实路径避免目录联接绕过检查。默认扭蛋目录可以恢复。
- 选择时和启动时检查目标，实际探测写权限；复制模式不合并已有目标库、不覆盖同名应用。
- 手工逐文件复制到目标旁的专用临时目录，避开 Electron/Windows 的 emoji 路径 `fs.cp` 崩溃。复制完整数据，包括未正常退出时可能需要恢复的 SQLite WAL。
- 源目录始终保留。全部复制成功后才替换用户选定的空目录并保存新路径；不会递归删除用户选择的目录。设置保存失败则继续使用原库，已完成的新副本保留；检查后可关闭复制并选择该副本。
- 复制失败保持原库并提示原因。临时目录以 `.appgacha-eggs-copy-` 命名，不会被当作扭蛋库；进程被强制结束时可能留下临时副本。自动复制拒绝符号链接/特殊文件，避免漏数据或跟随链接读取库外文件。
- 外置磁盘不可用时提示用户重新连接或改选目录，不静默改回默认库。

## 异常恢复与云端替换

- 配置损坏、路径变成普通文件、读取／写入权限不足时，进入无库恢复状态：主窗口和设置仍可打开，不允许向默认位置偷偷写入。内置新建／续建在调用模型前检查目录；MCP 在目录恢复前不能初始化可写服务。
- 设置中可以明确选择可用目录（恢复时不复制不可用的旧库），完整重启后生效。配置损坏时，保存新选择前先把原文件复制为 `egg-storage.json.recovery-<id>.bak`；备份失败则拒绝覆盖配置。取消或应用恢复失败仍不会静默切回默认库。
- 云端安装先把完整文件复制到目标库内的 `.appgacha-install-*` 暂存目录，再用同卷 rename 替换。复制或备份失败不删除原扭蛋；替换失败尝试还原。回滚再次失败时保留 `previous` 原始副本并在错误中给出路径。新下载／云端副本也不会在拷贝未完成时显示为正式扭蛋。
- 这不是断电事务保证。强制结束进程／断电可能留下暂存或原始备份，请保留文件检查恢复，不要批量清理隐藏目录。复制期间需要额外磁盘空间。

复制保留应用 ID，因此快捷方式的 `appgacha://egg/<id>` 仍可定位应用。Windows 旧快捷方式的自定义图标可能仍引用旧目录；若之后自行清理原目录，可从新库重新创建快捷方式。

## 验证边界

单元测试覆盖重启生效、完整复制、取消、恢复、非空目标、嵌套路径/目录联接、磁盘缺失、复制与配置保存失败，以及开发/安装模式的路径分流。`npm run test:mcp` 在隔离 Electron profile 中验证 C 盘到 E 盘复制带中文/emoji 名称的目录、保留 WAL、原文件不删除，以及 MCP 使用自定义目录直接入柜。

macOS 原生选择器和最终安装包仍需实机验证。此功能不改变版本号、不自动发布，也不会替用户修改正在使用的真实目录。

发布前逐项执行 [安装包手动验收清单](./release-manual-checklist.md)。
